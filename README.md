### 🚀 About Me
- 🎓 I am an IT student at **The Islamia University of Bahawalpur**, currently developing **COD-Shield**—an AI-driven system designed to predict return risks for Cash-on-Delivery (COD) orders in Pakistan.
- 📱 Focused on cross-platform mobile & web frontend development using **Flutter**, paired with robust backend integration and **PostgreSQL** database management.
- 📚 Bridging software engineering with analytical marketing concepts (including market segmentation, strategic audits, and the 4 Ps).
- ⚡ Fun fact: I love exploring 3D mechanical CAD designs, superbike engineering (like the Kawasaki ZX-10R), and cutting-edge tech innovations!
